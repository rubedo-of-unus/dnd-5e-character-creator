# D&D 5th Edition Character Creator (2014 Ruleset)
## Background
The application is aimed to creating conveniences for players that wish to create a character using the rules of 5th edition. Though many applications exist for that purpose, this solution does not restrict any races, classes or backgrounds behind memberships, subscriptions or payments. In addition, this solution allows the user to create their own races, classes and backgrounds for homebrewing purposes.

## Installation and Usage
1. Download the repository (Zipped Folder)
2. Unzip the folder in the desired destination folder
3. Double-click on the file `index.html` => this will open the file on your default browser

NOTE: If you understand HTML, CSS or JavaScript, feel free to edit the files as necessary. However, if you lack any programmatic knowledge, do not change anything in the code, as it may ruin the application.

## Current Progress
The application currently allows the user to:
- Upload character image
- Apply damage and healing
- Add equipment and check for encumbrance
- Select race, subrace, class and background
- Enter character name
- Apply racial and sub-racial bonuses to statistics automatically once a race and a subrace are selected
- Add backstory (with support for markdown)
- Use the dice roller
- Check for death saves
- Heal using hit dice by clicking short rest
- Regain hit dice by clicking long rest
- Increment and decrement level, HP and ability scores to user preference
- Reload application to generate a new player
- Add languages manually
- Automatically sets speed, size and proficiency bonus
- Perform skill checks and saving throws
